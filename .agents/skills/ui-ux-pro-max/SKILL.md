# UI/UX Pro Max

Use the UI/UX Pro Max methodology for any task that changes how the Gasto Certo interface looks, feels, moves, or is interacted with.

## Priorities

1. Accessibility and keyboard/touch usability.
2. Clear hierarchy and responsive/mobile-first layout.
3. Consistent design system, spacing, typography, colors and iconography.
4. Performance-conscious motion and visual effects.
5. Production-ready states: loading, empty, error, success, disabled and focus.

## Gasto Certo application

Treat Gasto Certo as a personal-finance/productivity product. Favor clarity, trust, legibility, fast scanning of balances and transactions, and restrained visual effects. Avoid decorative UI that competes with financial information.
